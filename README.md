# Pontis

CS4398 MVC project - Flutter/Dart.

## Layout
- `lib/model`       - AbstractModel, ModelEvent, ModelListener, concrete models
- `lib/view`        - views (widgets implementing ModelListener)
- `lib/controller`  - AbstractController, concrete controllers
- `test/`           - unit tests
- `docs/`           - UML, statecharts, API docs, architecture, acceptance screenshots
- `archive/`        - helper to build the submission archive
